# assets

Put the hero image or video here, then uncomment the matching tag in
`index.html` (search for "TO USE YOUR OWN IMAGE").

- `hero.jpg` — portrait crop reads best; the frame is 3:4 with an arched top
- `hero.mp4` + `hero-poster.jpg` — keep it muted, looped and under ~5 MB

Until a file is present the aperture renders as a lit plaster surface. That is
a deliberate state, not a broken image.
